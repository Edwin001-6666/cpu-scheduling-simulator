C4 — ALGORITHM COMPARISON
==================================================

Files:
- app.py [MODIFIED] — added algorithm comparison section

Functions:

  run_algorithm_comparison(processes, quantum)

  - Runs all 4 algorithms:
    FCFS
    SJF
    Priority
    Round Robin

  - Uses the same validated workload for every algorithm
  - Returns:
      dict[str, SimulationResult]
  - Uses the existing scheduling algorithms and metrics layer
  - Does not duplicate scheduling logic

  _find_best(results)

  - Identifies the best algorithm for each metric
  - Handles ties explicitly
  - Lower-is-better:
      Waiting Time
      Turnaround Time
      Response Time

  - Higher-is-better:
      CPU Utilization
      Throughput

  render_comparison_table(results, best)

  - Displays:
      Algorithm
      Average Waiting Time
      Average Turnaround Time
      Average Response Time
      CPU Utilization
      Throughput

  - Highlights the best performer for the current workload
  - Uses "Best for this workload" wording rather than making
    universal claims
  - Displays ties explicitly

  render_comparison_chart(results)

  - Creates a grouped comparison chart
  - Compares:
      Average Waiting Time
      Average Turnaround Time
      Average Response Time
  - Uses matplotlib
  - Includes value labels
