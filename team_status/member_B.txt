- Extra columns supported and reported
- Blank lines skipped
- Quoted fields supported
- Windows CRLF supported
- Clear row-level parsing errors

The CSV layer converts uploaded CSV data into Process objects.
Semantic validation is then handled separately by the validation
layer.


==================================================
SEPARATION OF CONCERNS
==================================================

The backend follows a modular pipeline:

  CSV Input
      ↓
  parse_processes_csv()
      ↓
  validate_processes()
      ↓
  algo.schedule()
      ↓
  compute_metrics()
      ↓
  Final SimulationResult

Responsibilities are separated as follows:

- CSV parsing → converts CSV data into Process objects
- Validation → verifies process and scheduling inputs
- Scheduling engine → executes the selected algorithm
- Metrics layer → calculates additional performance metrics
