API:
  compute_metrics(result: SimulationResult, processes: Sequence[Process])
      -> SimulationResult

  Call AFTER algo.schedule(). Returns an enriched SimulationResult with:
    - ProcessMetrics.response_time filled for every process
    - SimulationResult.average_response_time filled
    - SimulationResult.cpu_utilization filled (percentage, 0.0–100.0)
    - SimulationResult.throughput filled (processes per unit time)

Formulas:
  response_time      = first_dispatch_start_time - arrival_time
                       (first_dispatch determined from execution_segments)
  average_response_time = mean(response_time for all processes)
  cpu_utilization    = (busy_time / total_time) * 100.0
                       busy_time  = sum of non-idle segment durations
                       total_time = last_segment.end_time - first_segment.start_time
  throughput         = n_processes / total_time

Design decisions:
  - compute_metrics is a pure post-processing function — no algorithm logic
  - Derives all values from SimulationResult.execution_segments (the Gantt)
  - Does NOT mutate input SimulationResult or process list
  - Works correctly for Round Robin (preemptive) by scanning segments in order
    to find each process's first dispatch
  - Works correctly with CPU idle periods (idle segments excluded from busy_time)
