Validation API:
  validate_processes(processes) -> ValidationResult
    Validates a list/tuple of Process objects before they reach any algorithm.
    Rules enforced:
      - List must be non-empty
      - Each element must be a Process instance
      - PID must be a non-empty string and must not equal IDLE_PROCESS_ID
      - All PIDs must be unique
      - arrival_time must be int >= 0
      - burst_time must be int > 0
      - priority must be int (any integer; lower = higher priority per DECISIONS.txt)

  validate_round_robin_quantum(quantum) -> ValidationResult
    Validates a Round Robin time quantum value.
    Rules enforced:
      - Must not be None
      - Must be a plain int (not bool, not float, not str)
      - Must be > 0

  ValidationResult:
    .is_valid  (bool)             — True if no errors
    .errors    (list[ValidationError]) — structured error list (empty when valid)
    bool(result) == result.is_valid

  ValidationError:
    .field       (str)            — field name that failed (e.g. "burst_time")
    .message     (str)            — human-readable message for UI display
    .process_id  (str | None)     — PID of the offending process, or None

Design decisions:
  - Validation is COMPLETELY independent of Streamlit, algorithms, and storage
  - Validation NEVER silently modifies or discards invalid input
  - All errors are collected and returned (not raised); caller inspects result
  - Laptop C (Streamlit UI) can call these functions directly and display
    result.errors as friendly messages
